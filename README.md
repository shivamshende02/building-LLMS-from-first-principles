# building-LLMS-from-first-principles
A modular, framework-free engineering repository implementing core generative AI primitives—from raw tokenizers, chunking engines, and embedding pipelines to custom LLMs and multi-modal architectures


🎯 Objective
Most modern AI development relies on high-level abstractions (LangChain, LlamaIndex, Hugging Face transformers). This repository strips away the wrappers to implement and scale Large Language Models, Embedding models, RAG chunking strategies, and Multi-modal architectures completely from scratch using raw PyTorch and low-level serving infrastructure.
